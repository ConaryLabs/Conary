# Conary Workspace Rule

Read and follow the repository-root `AGENTS.md` before changing this project.
Route the actual task with `scripts/agent-context.sh --path <file>` or
`--feature <slug>` and load only the resulting task packet's sources and
canonical docs. Do not preload the complete feature-ownership map.

`docs/llms/README.md` is the broader orientation map. It and this rule contain
no independent project policy.
